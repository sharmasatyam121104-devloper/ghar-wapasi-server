# Ghar Wapasi Server

Backend API for **Ghar Wapasi**, a platform designed to help identify missing and unidentified persons and reconnect them with their families.

## Tech Stack

* Node.js
* Express
* TypeScript
* MongoDB

## Modules

* User
* Family
* Police
* NGO
* Citizen
* Admin
* Super Admin

## Setup

```bash
npm install
npm run dev
```
